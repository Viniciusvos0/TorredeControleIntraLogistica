# TorredeControleIntraLogistica

Neste projeto desenvolvi um ecossistema de BI totalmente automatizado, desde a extração dos dados até o BI.

O projeto se iniciou no desenvolvimento de diversos painéis e Dashboards em Power BI, substituindo toda interface de indicadores produzidos em excel.

Após o desenvolvimento do DataViz semi automatizado comecei os testes com a automatização do ETL com robôs virtuais utilizando Python.

A partir do primeiro robô percebi a necessidade de introduzir servidores devido ao método de ETL desenvolvido, os robôs faziam um DataScraping de um sistema baseado em Cobol, portanto em algumas etapas ocupava a tela dos computadores.

Após receber os servidores consegui gerar diversos indicadores de forma 100% automática, ou seja, sem nenhuma interferência humana. Essa etapa do projeto contemplava apenas um CD da companhia, o CD do Rio de Janeiro.

Ao perceber a capacidade do projeto,  gestores da alta gestão da empresa (Grupo Profarma) foi solicitada a ampliação do projeto para os outros 14 CDs da Companhia. 

Trabalhei na ampliação do projeto e na fase final do projeto Torre de Controle IntraLogística estava atendendo os 15 CDs da companhia na geração dos principais indicadores de desempenho nas áreas de Abastecimento, Geográfica (Inventários), Picking (Erro Interno, Fata, Exclusão).
